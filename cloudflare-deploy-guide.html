🚀 คู่มือ Deploy GenerateFlow ไปยัง Cloudflare

อธิบายแบบมือใหม่: ทำไมต้องตั้งค่าแบบนี้ และทำไม error ที่เจอมาถึงเกิด

1ภาพรวม: โปรเจกต์นี้คืออะไร

GenerateFlow เป็นเว็บที่เขียนด้วย Next.js (App Router) ซึ่งมี API Route (app/api/generate/route.ts) ที่ต้องรันโค้ดฝั่ง server ได้ ไม่ใช่เว็บ static ธรรมดา

Cloudflare ไม่ได้รัน Next.js ตรงๆ — ต้องผ่านตัวแปลงที่เรียกว่า OpenNext adapter (@opennextjs/cloudflare) ก่อน เพื่อแปลงโค้ด Next.js ให้กลายเป็นไฟล์ที่ Cloudflare Workers รันได้

🍳 เปรียบเทียบง่ายๆ:
ลองคิดว่าโค้ด Next.js ของคุณคือ "วัตถุดิบในตู้เย็น" (ข้าว, ผัก, เนื้อ)
Build = เอาวัตถุดิบมา "ปรุง" จนกลายเป็นจานอาหารพร้อมเสิร์ฟ (โฟลเดอร์ .open-next/)
Deploy = เอาจานอาหารที่ปรุงเสร็จแล้วไป "เสิร์ฟ" ให้ลูกค้า (อัปโหลดขึ้น Cloudflare)

❌ ถ้า ไม่ build ก่อน แล้วสั่ง deploy ทันที = เหมือนเสิร์ฟจานเปล่าให้ลูกค้า เพราะยังไม่มีอาหารให้เสิร์ฟ!

2Flow การ Deploy ที่ตั้งใจไว้

โปรเจกต์นี้ใช้วิธี deploy ผ่าน Git — ไม่ต้องรันคำสั่งจากเครื่องตัวเอง:

1
คุณ git push โค้ดขึ้น GitHub
⬇
2
Cloudflare ตรวจพบ push ใหม่ → เริ่ม "Build"
⬇
3
รัน Build command → สร้างโฟลเดอร์ .open-next/
⬇
4
รัน Deploy command → อัปโหลด .open-next/ ขึ้น Cloudflare Workers
⬇
🌐
เว็บออนไลน์ที่ https://generateflow.<subdomain>.workers.dev

ปัญหาที่เจอทั้งหมดเกิดจากขั้นที่ 3 ("Build command") ไม่ได้ทำงาน ทำให้ขั้นที่ 4 หาไฟล์ไม่เจอ

3คำศัพท์ที่ต้องรู้

คำศัพท์ความหมาย
wrangler.jsonc ไฟล์ตั้งค่า Worker บอก Cloudflare ว่าไฟล์เริ่มต้น (entry point) อยู่ที่ไหน — ในโปรเจกต์นี้คือ .open-next/worker.js
.open-next/ โฟลเดอร์ผลลัพธ์ที่ได้จากการ build — ไม่ได้เก็บใน Git (อยู่ใน .gitignore) ต้องสร้างใหม่ทุกครั้งที่ deploy
Build command คำสั่งที่ Cloudflare รัน "ก่อน" เพื่อแปลงโค้ด Next.js → .open-next/
Deploy command คำสั่งที่ Cloudflare รัน "หลัง build" เพื่ออัปโหลดผลลัพธ์ขึ้น Cloudflare Workers
npx wrangler deploy คำสั่ง deploy แบบเดิม (ทันที 100%)
npx wrangler versions upload คำสั่ง deploy แบบใหม่ของ Cloudflare (Gradual Deployments) — เป็นค่า default ปัจจุบัน

4ปัญหาที่เจอ และสาเหตุ

ครั้งที่ 1: "Could not find compiled Open Next config"

ตอนนั้น Deploy command = npx wrangler deploy

Executing user deploy command: npx wrangler deploy
OpenNext project detected, calling `opennextjs-cloudflare deploy`

ERROR Could not find compiled Open Next config, did you run the build command?
สาเหตุ
npx wrangler deploy เห็นว่าเป็นโปรเจกต์ OpenNext เลยส่งต่อให้ opennextjs-cloudflare deploy ทำงาน แต่คำสั่งนี้ขั้นแรกจะไปหาไฟล์ "ผลลัพธ์การ build" ก่อนเสมอ — เนื่องจากไม่มีขั้นตอน build เกิดขึ้นเลย (ไม่เห็น log การ build ก่อนหน้านี้) จึงหาไฟล์ไม่เจอ

ครั้งที่ 2: "The entry-point file at .open-next/worker.js was not found"

ตอนนั้น Build command = None และ Deploy command = npx wrangler versions upload

Executing user deploy command: npx wrangler versions upload

✘ [ERROR] The entry-point file at ".open-next/worker.js" was not found.

  This might mean that your entry-point file needs to be generated
  (which is the general case when a framework is being used).
  If that's the case please run your project's build command and try again.
สาเหตุ
คำสั่งนี้ไม่ได้ผ่าน opennext wrapper เหมือนครั้งที่ 1 — มันเช็คไฟล์ .open-next/worker.js ตามที่ wrangler.jsonc กำหนดไว้ตรงๆเลย พอ Build command เป็น None ไฟล์นี้จึงไม่ถูกสร้างขึ้นมาตั้งแต่แรก
💡 สรุปสาเหตุทั้งสองครั้ง: เหมือนกัน 100% — คือ ไม่มีใครรัน opennextjs-cloudflare build เพื่อสร้างโฟลเดอร์ .open-next/ เลย error message ต่างกันแค่เพราะ deploy command คนละตัวไปเช็คไฟล์คนละจังหวะ

5วิธีแก้ไข ✅

เข้าไปที่ Cloudflare Dashboard → Workers & Pages → generateflow → Settings → Build

ตั้งค่าดังนี้
ช่องค่าที่ต้องตั้ง
Build command npx opennextjs-cloudflare build สำคัญที่สุด
Deploy command npx wrangler versions upload (ค่า default เดิม ไม่ต้องเปลี่ยน)
Root directory / (ค่า default เดิม)

เมื่อ Build command รันสำเร็จ มันจะสร้างโฟลเดอร์ .open-next/worker.js ขึ้นมา จากนั้น Deploy command ก็จะเจอไฟล์และอัปโหลดได้ตามปกติ

ทางเลือกอื่น (ถ้าวิธีบนยังไม่ผ่าน)

ตั้ง Build command เป็น None (ว่าง) แล้วใส่ Deploy command เป็น npm run deploy แทน — เพราะ script นี้ใน package.json ทำทั้ง build และ deploy ในคำสั่งเดียวอยู่แล้ว: 

"deploy": "opennextjs-cloudflare build && opennextjs-cloudflare deploy"

6Checklist สรุป

  • โค้ดถูก push ขึ้น GitHub branch main แล้ว
  • เชื่อม Cloudflare Workers Builds กับ repo แล้ว
  • ชื่อ Worker ตรงกับ name ใน wrangler.jsonc (คือ generateflow)
  • Build command = npx opennextjs-cloudflare build
  • Deploy command ปล่อยเป็น default (npx wrangler versions upload)
  • กด Save → กลับไปแท็บ Deployments → กด Retry deployment

หลัง deploy ผ่านครั้งแรกแล้ว ทุกครั้งที่ git push ขึ้น main Cloudflare จะ build + deploy ให้อัตโนมัติตาม flow นี้เสมอ ไม่ต้องตั้งค่าซ้ำอีก
